# 龙岗区

现用2026小学学区数据：131条学校/校区，1134个有地图命中的坐标组。

- `学校数据/`、`schools.json`：学校目录。
- `政策文本/`、`texts.json`：官方招生范围原文及出处。
- `评价数据/官方学区范围.json`、`polygons.json`：官方学区polygon。
- `小区数据/`、`地理数据/`：小区及学校位置。
- `Gold/`：小区代表点对应的完整学校集合。
- `政策规则/`：大学区、共享学区与资格条件。
- `数据清单/`：数据校验记录。

Gold是地图代表点归属，不是家庭完整招生资格。多校命中全部保留，大学区不按成员名单自动扩校。
