# 福田官网学区地图核查

官网：https://zs.szft.gov.cn/visitftgbxyxqdt

检查依据：2026-11-11 获取的官网前端源代码；本项目已存档的官方地图边界。未重新获取当前接口全部学校边界，几何结论对应存档数据。

## 结论

- 绘图逻辑逐校读取 otherxx[i].MAPDATA，每所学校建立一个 BMap.Polygon；没有在绘图时按大学区合并。
- 官网并非完全不体现大学区：另有 Dxqlist 分组，点击命中地段时可汇总组内学校信息。分组信息与边界形状是两层。
- 益田村、东海、上沙、莲花四组大学区成员校的存档 polygon 均不相同，主体分开；益田村和莲花存在很小面积的相互覆盖。上沙小学组在地图分组中名称为“沙头片区”。
- 共享学区存在不同表现：福民四校边界高度重合，交集分别占各参与学校面积约 99.13%—99.91%；景田南两校约 99.10% 和 99.96%。所以不能把全部 polygon 都解释为互不重合的单校原始地段。
- 香梅三校边界无面积交集；上梅林的梅红边界被梅丽包含，但只有梅丽面积的约 1.69%，三校没有共用同一完整边界。
- 福南、梅林原始 polygon 无效；涉及它们的面积运算未进行，未修复或改写原数据。

## 方法与限制

78 条整理后顶点坐标与存档原始 MAPDATA 完全一致。使用 Shapely 对有效原始 polygon 检查几何相等和交集。比例为原始 BD09 坐标平面面积比例，仅用于判断重合程度，不是测绘面积；零面积交集不排除接边。

本次未核查长沙现状；只能说“逐校存 polygon、政策分组另外表达”这一结构相似，不能据此认定全部政策语义一致。
