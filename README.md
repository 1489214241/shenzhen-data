# 深圳data

深圳市小学学区数据、实验代码和实验结果，参照长沙市仓库按区整理。

| 现用区 | 学校/校区 | 有地图答案的坐标组 | 数据 |
|---|---:|---:|---|
| 龙华区 | 71 | 627 | [龙华区](龙华区/) |
| 龙岗区 | 131 | 1134 | [龙岗区](龙岗区/) |

## 目录

```text
龙华区/                 学校、小区、官方文字、polygon、Gold和政策规则
龙岗区/                 学校、小区、官方文字、polygon、Gold和政策规则
models/school-zone/     模型、规则、特征、训练、评价代码及配置
experiments/            各轮实验结果、逐题输出、配置和中文报告
历史资料/               福田、南山旧数据，不属于现用区
数据清单/               数据来源、公开副本校验清单
构建工具/               原标准数据构建工具
```

数据、代码和结果都是仓库里的普通文件，克隆即可查看；不需要分包下载或Git LFS。训练缓存、权重和重复中间输入不上传。

## 使用

```bash
git clone https://github.com/1489214241/shenzhen-data.git
cd shenzhen-data
python experiments/evaluate.py
```

上面的命令无需第三方依赖，使用公开的龙华、龙岗Gold重新计算最新实验13组逐题预测的成绩，并核对原记录。

训练与推断源码见 [models/school-zone](models/school-zone/README.md)。历史实验保留原配置和溯源路径；不包含训练缓存，因此重新训练需要按相应实验脚本重建输入，不能把成绩复核称为从零重训。

## 数据含义

Gold为小区代表点落入官方学区polygon所得的学校集合，不等于家庭实际招生资格。多校命中全部保留；大学区保留原地段，共享按实际共同范围处理，不作传递扩校。

现用政策为2026年，标准数据版本为2026-11-11，公开整理于2026-11-14。官方文字的URL和原文位置保留在各区政策文本中。原始目录中的旧manifest保留溯源含义，本次公开文件以 `数据清单/发布文件校验.json` 为准。第三方资料及代码保留其原有权利和许可，不对全部混合材料另授统一许可。
