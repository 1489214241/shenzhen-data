## 最新：固定参照，比较训练方式

本轮不增加核验，沿用目标1的84个模拟核验参照及相同1095题。四个版本均独立逐校输出；只对照源区训练参照多少、查询是否按学校构造。每版3个种子，政策处理相同。

本轮未改善旧模型表现。最好的新版本43.74%在源区校准后实际退回原始单校输出，多校仍靠既有政策补校；不能把这个成绩解释为已学会新的多校组合。

## 按学校补缺实验

按学校补缺：已有文字证据参照计入目标，每校总计至少1、2、3个；同楼盘组只核验、计费一次。新增答案来自 **Gold模拟核验**，尚未实际向学校采集。

以下三档统一在 **1095个未知小区** 上比较；全部既有/新增参照项目组及重复点退出测试。多一个或少一个学校都算错，全部方法保留相同政策处理。

| 每校总目标 | 两区新增核验小区 | 原Modern微调 | 完整组合分支 | 完整组合＋距离回退 |
|---|---:|---:|---:|---:|
| 1个 | 84 | 46.94% | 30.87% | 46.94% |
| 2个 | 167 | 52.69% | 39.82% | 54.34% |
| 3个 | 255 | 52.51% | 46.67% | 57.26% |

目标1个仍有大康小学、西坑小学两所学校未补到。目标1个时，200/202所学校有部分或完整参照，但只有44.93%的测试小区，其完整学校组合出现在新增参照中。学校覆盖不能替代组合覆盖。低预算下完整组合主分支未达到预期，**未替换默认模型**。

## 使用

```bash
git clone https://github.com/1489214241/shenzhen-data.git
cd shenzhen-data
python experiments/evaluate.py
python experiments/evaluate_reference_trials.py
```

两个命令均无需第三方依赖。第一个重算历史树模型13组成绩；第二个重算固定512点及按学校补缺三档实验，检查核验成本、项目组排除、完整学校集合预测和最近邻重放。

训练与推断源码见 [models/school-zone](models/school-zone/README.md)。历史实验保留原配置和溯源路径；常规目录不包含完整训练缓存；上方 Release 补齐指定冻结依赖，其余重新训练输入仍需按相应实验脚本准备，不能把成绩复核称为从零重训。

## 数据含义

Gold为小区代表点落入官方学区polygon所得的学校集合，不等于家庭实际招生资格。多校命中全部保留；大学区保留原地段，共享按实际共同范围处理，不作传递扩校。

现用政策为2026年，标准数据版本为2026-11-11，公开整理于2026-11-14。官方文字的URL和原文位置保留在各区政策文本中。原始目录中的旧manifest保留溯源含义，本次公开文件以 `数据清单/发布文件校验.json` 为准。第三方资料及代码保留其原有权利和许可，不对全部混合材料另授统一许可。
