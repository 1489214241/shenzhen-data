本阶段目标
将福田、南山已有独立小区点源、官方小学服务页学校属性、原始共享结构整理为可审计的完整源包。本阶段不生成小区—学校正负关系、不选择参照、不解析政策名字、不构建模型数组；它为后续独立冻结的阶段 B 提供输入。阶段 A 不能证明环境关系有用，也不产生新的模型成绩。

每条 source_id 为 fdc:<原始完整文件SHA>:row:<原文件从0起全局行号>，保留完整原始行、原序、源文件及 JSON pointer。building_name 不作为身份。按原始 BD09 数值坐标精确相等分组，1210/1265 组合计 2475；先分组再转换，不四舍五入、不按名字合并。组 ID 绑定源 SHA 和坐标 float.hex，组序为首次出现顺序，保留所有源成员。跨区同坐标若出现则保留冲突并停止验收，不删样本。

学校源范围和字段
仅访问两个 public_map_data.json 的 /school_data 数组，完整保留福田78、南山80条，以(源区代码,ORG_ID)为学校键；不用学校名合并，不按几何有无过滤。字段只投影 ORG_ID/MC/XQ/DZ/POINTX/POINTY/APP_ID/XH/GXSJ/XZSJ，保留原始类型、源序、指针、源 SHA；XQ 另保留完整解码字符串的字符范围和原文，3条空 XQ 照常保留。GXSJ/XZSJ 仅系统元数据，不能当政策年份。

时间/学段依据是“2026指南选定服务的2026-10-23快照”和小学服务入口，非每条数据存在独立政策年度/学段证据。

共享结构与政策语义边界
两个源包 groups 仅保存 XXID/DXQ_ID/DXQ_MC 三项非几何属性和 XXID 原序逗号 token；不丢不在当前小学名册中的 ID，不因名称“初中大学区”丢整行。即使输入额外有 geometry/MAPDATA，也绝不投影。南山 live HTML 只对 xxGxFwdzJson 和 xxGxFwdzNotXqList 两个指定严格 JSON 字面量解码，保留原字面文本、字符范围、行号、源 SHA、方向和顺序，不 eval JavaScript。
保留 fn_xqdt_getxxGxFwdzJson 的非几何优先级证据：已有 groups 列表优先，仅在 undefined 时使用定向共享列表。阶段 A 不执行该优先级、不求传递闭包、不构建有效归属集合；popup 文本来源映射也仅作来源结构。
XQ 可包含共享招生、户籍/住宅资格、栋范围/排除、地址、几何定位等，不能一概称基础地段。本阶段原文逐字保存。阶段 B 必须另行审定条件分流、完整名字精确匹配和别名证据；不得删括注、自动生成“员工宿舍”等通用别名、去“小区”后缀、母盘包含各期、由未匹配制造负例、由共享图无条件闭包。

执行顺序
1. 先完成本计划与全部代码，运行 selftest.py，仅合成源和既有纯坐标代码可读。
2. 独立审查员静审，写 v1/prebuild_review.json；approved=true、scope=60_phase_a_source_package、files 精确绑定5个 .py、本计划和合成回执。存在阻断项先修，再重新合成验收与审核。
3. root 执行 build.py freeze，只核哈希/运行版本，不读取真实源行作提取，写 source_freeze.json。
4. root 执行 build.py build，完整提取真实源包；任何源计数、ID、坐标、空值或版本不一致立即停止，不自动修复/删样本。
5. root 执行 verify.py，冻结依赖复核、完整重放以及独立的原始行号筛选、原数值坐标分组、字段逐项保留、共享字面量范围和投影数值往返验证。独立审查结果与回执均通过后方称源包已建成。
